찰픽 탐색 보완 v10 (2026-10-24)

1. 찰픽 로고 클릭 시 첫 화면으로 복귀하며 테마·검색·필터를 초기화합니다.
   보관함과 취향은 유지하며, 브라우저 뒤로가기/앞으로가기도 유지합니다.
2. 태그와 플랫폼에 작품 수를 복원했습니다.
   현재 선택 조건에 맞는 작품만 세며 선택하거나 해제할 때 갱신됩니다.
3. 태그와 플랫폼은 작품 수 내림차순, 동률은 가나다순으로 정렬합니다.
   애플TV에만 결과가 있으면 애플TV가 맨 앞에 나옵니다.
4. 앱 연결, 카드 전체 클릭, 찰픽 심볼 광고, 숫자 없는 수동 작품 더보기는 유지합니다.

적용 방법
- 웹업로드용 ZIP을 풀고 안의 폴더와 파일을 저장소 최상위에 올립니다.
- ZIP 파일 자체나 바깥 폴더를 올리지 말고 api/public/scripts/server 구조를 유지합니다.
- 같은 경로의 파일만 교체하고 기존 비밀 환경설정은 GitHub에 올리지 않습니다.
- 배포 후 새로고침하여 테마 → 찰픽 로고 → 홈, 태그 수 갱신, 플랫폼 정렬을 확인합니다.
- DB 변경이나 SQL 실행은 필요하지 않습니다. 과거 전체 교체 SQL을 실행하지 마세요.
- 로컬 확인 주소: http://localhost:4177/

이 파일은 로컬 수정본이며 운영 배포와 GitHub 커밋은 수행하지 않았습니다.
