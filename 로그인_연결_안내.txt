찰픽 네이버·카카오 로그인 — 직접 설정할 부분

로그인 기능의 코드는 준비되어 있습니다.
실제 로그인을 열려면 서비스 소유자 계정에서 아래 설정이 필요합니다.
현재 적용된 '액션파 독자'는 추천용 임시 프로필이며 소셜 로그인 계정은 아닙니다.

1. 네이버 로그인 앱 만들기
   https://developers.naver.com/apps/#/list
   찰픽의 웹 서비스 주소: https://chalpick.kr
   Callback URL:
   https://chalpick.kr/api/auth?action=callback&provider=naver
   표시용 별명을 설정하고, 일반 이용자에게 공개하기 위한 검수 절차를 확인하세요.

2. 카카오 로그인 앱 만들기
   https://developers.kakao.com/console/app
   카카오 로그인을 활성화하고 닉네임 동의항목을 설정하세요.
   Redirect URI:
   https://chalpick.kr/api/auth?action=callback&provider=kakao
   REST API 키와 Client Secret을 사용합니다.

3. Vercel 찰픽 프로젝트에 연결값 등록하기
   프로젝트 Settings → Environment Variables에 아래 이름으로 등록하세요.
   AUTH_BASE_URL = https://chalpick.kr
   AUTH_SESSION_SECRET = 무작위 세션 암호화 키
   NAVER_CLIENT_ID = 네이버 앱의 Client ID
   NAVER_CLIENT_SECRET = 네이버 앱의 Client Secret
   KAKAO_CLIENT_ID = 카카오 앱의 REST API 키
   KAKAO_CLIENT_SECRET = 카카오 앱의 Client Secret

   비밀키는 채팅에 붙여넣지 말고 Vercel 설정에 직접 입력하세요.
   세션 키 생성 방법과 로컬 테스트 주소는 AUTH_SETUP.md에 있습니다.
   입력 후 이 프로젝트 전체를 재배포해야 설정이 반영됩니다.
   dist 폴더만 업로드하면 로그인 서버가 빠지므로 프로젝트 루트에서 배포하세요.

4. 실제 계정으로 확인하기
   네이버·카카오 각각 로그인 → 새로고침 후 유지 → 로그아웃을 확인하세요.
   코드 내부의 모의 인증 검증은 완료했지만 실제 제공자 로그인은 위 설정 후 확인해야 합니다.

현재 범위
• 로그인 상태는 암호화된 쿠키로 유지됩니다.
• 보관함과 취향은 현재 브라우저에 저장됩니다. 로그인만으로 다른 기기에 동기화되지는 않습니다.
• 찰픽의 운영 도메인에는 아직 이번 변경을 공개 배포하지 않았습니다.
• 상세 개발·운영 안내: AUTH_SETUP.md
