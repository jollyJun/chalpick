# 찰픽 메인페이지 리뉴얼 v4

## 최신 DB 연결 업데이트 — 2026-10-23

메인 작품 목록은 이제 `/api/catalog`를 통해 Supabase의 최신 공개 대상 작품을 읽습니다. 예전 2,500편 파일로 대체하지 않습니다. localhost 설정은 이 폴더의 `.env.local`에 있으며, Vercel에서는 `SUPABASE_URL`과 `SUPABASE_PUBLISHABLE_KEY`를 환경변수로 등록하고 프로젝트 루트 전체를 배포합니다. 관리자 키나 DB 비밀번호는 필요하지 않습니다. 자세한 내용은 [CATALOG_SETUP.md](CATALOG_SETUP.md)를 참고하세요.

화면은 DB 공개 대상 수, 실제 탐색 수, 확인된 성인 제외 수를 구분합니다. 미확인 이용등급은 전체이용가로 간주하지 않습니다. DB의 기념일·계절·날씨 태그도 함께 읽습니다. SQL을 다시 실행하거나 RLS를 끌 필요가 없습니다.

기준일: 2026-10-23. 기존 페이지와 데이터 파일을 보존하고 별도 폴더에서 제작한 찰픽 메인페이지입니다. 흰색 중심의 반응형 화면에 작품 탐색, 취향 추천, 상세 정보, 실제 플랫폼 인기순위를 구성했습니다.

## 실행

Node.js 24를 사용합니다. 프로젝트 폴더에서 다음을 실행합니다. 추가 npm 패키지는 필요하지 않습니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. Windows에서는 `미리보기.cmd`를 두 번 클릭할 수도 있습니다. 이 PC에서 미리보기가 실행 중이면 기존 화면을 엽니다. OAuth 로그인까지 시험할 때는 `localhost`와 `127.0.0.1`을 혼용하지 말고 [AUTH_SETUP.md](AUTH_SETUP.md)의 출처·콜백 설정을 따릅니다.

## 화면과 기능

- 기존 ‘누구의 취향으로 볼까요’ 사용자 전환 영역 삭제.
- 상단 매체 메뉴와 ‘내 취향 알아보기’ 링크 삭제. ‘취향이 닿는 곳’ 아래 전체·웹툰·웹소설·드라마·OTT·영화 선택을 배치했습니다. 애니메이션은 제외합니다.
- 실제 찰픽 로고, PC·태블릿·모바일 화면, 가로형·사이드형 광고 자리. 광고는 흰색 이미지에 ‘여기가 광고하는 자리입니다’ 문구를 표시합니다.
- 제목·작가·감독·출연배우·키워드 검색과 매체·플랫폼 필터.
- 장르 35개, 소재·배경 63개, 인물·관계 42개로 나눈 상세 태그 탐색과 작품 수 표시.
- 태그 수는 선택한 모든 조건을 적용한 현재 결과에서 집계하며, 같은 분류의 선택도 포함합니다. 세 분류 모두 개수 내림차순, 동점은 이름순으로 표시합니다. 0개 태그는 마지막에 회색으로 표시합니다.
- 플랫폼 필터에서 문피아·미스터블루를 제외했습니다. 원본 작품 정보와 공식 감상 링크는 보존합니다.
- 현재 취향에 따른 정렬, 유사픽, 발견픽, 액션·무협·스릴러 중심의 몰입 추천과 선정 기준 안내.
- 작품 상세의 소개·이용등급·공식 감상처·제작진·출연진 및 같은 제작진의 다른 작품 탐색.
- 네이버 시리즈·Netflix 공식 자료에 근거한 매체별 인기순위와 출처·집계기간 표시.
- 접속할 때 자동으로 선정하는 테마 한 개. 실제 추천 자료에 연결한 계절·비/폭풍·눈·한국 기념일 태그를 사용하며 테마 안에서 취향순으로 정렬합니다. 낮·밤·맑음·흐림은 제외합니다.
- 이 브라우저에 저장하는 보관함과 취향 설정.
- 네이버·카카오 OAuth 연결 코드. 제공자 앱과 서버 환경변수를 설정해야 실제 로그인이 활성화됩니다.
- 기존 v16 취향테스트 파일은 `/taste/`에 보존했으며, 메인에서 이동하는 링크는 제거했습니다.
- 검색 결과 없음, 자료 연결 실패, 표지 로딩 실패 시 대체 표시.

## 화면 사용법

1. 상단 검색창 또는 작품 탐색 안의 검색창에 제목·제작진·키워드를 입력합니다.
2. 장르·소재와 배경·인물과 관계 탭에서 원하는 태그를 고릅니다. **장르·소재와 배경·인물과 관계에서 선택한 태그가 모두 일치(AND)**하는 작품을 찾습니다. 예를 들어 판타지·액션·모험을 고르면 세 태그를 모두 가진 작품만 나옵니다. 플랫폼은 선택한 감상처 중 하나 이상에 제공되는 작품을 찾습니다. 선택한 조건을 개별 해제하거나 필터 초기화를 사용할 수 있습니다.
   태그 옆 숫자는 현재 결과에 포함된 작품 수입니다. 결과가 없는 미선택 태그는 흐리게 표시하고 선택을 막습니다. 이미 선택한 0개 태그는 해제할 수 있습니다. 매체 변경 시 검색어·태그·플랫폼 조건을 유지합니다.
3. 취향순·공개연도순·가나다순으로 정렬하고 ‘작품 더 보기’로 결과를 이어 봅니다. 공개연도는 업데이트 날짜와 다른 값입니다.
4. 작품 표지나 제목을 누르면 상세 정보를 봅니다. 공식 감상처 링크는 제공자 페이지를 새 창으로 열며, 책갈피 버튼은 내 보관함에 저장합니다.
5. 임시 취향 표시 또는 탐색 영역의 취향 요약을 눌러 좋아하는 키워드를 쉼표로 구분해 변경합니다. ‘임시 취향으로 되돌리기’는 아래 기본 프로필을 다시 적용합니다.
6. 인기 작품의 매체 탭을 바꿔 탐색합니다. ‘지금 이 순간의 이야기’는 자동으로 선정한 테마 한 개를 표시하며 버튼을 누르면 해당 테마의 작품을 취향순으로 볼 수 있습니다. 순위에서 카탈로그에 없는 작품은 공식 작품 페이지로 연결할 수 있습니다.

## 임시 취향과 로그인

첫 방문의 기본 임시 프로필은 **액션파 독자 — 액션·무림·먼치킨·회귀**입니다. 저장된 다른 취향이 있으면 그 값을 유지합니다. 임시 프로필을 적용하는 것만으로 회원 계정이나 로그인 세션을 만들지 않습니다.

취향과 보관함은 현재 브라우저의 localStorage에 저장됩니다. 소셜 로그인 성공 후에도 자동으로 다른 기기에 동기화되지 않으며, Supabase 회원 행을 생성하지 않습니다. 네이버·카카오의 실제 동의 화면과 세션 처리는 별도 서버 코드가 담당합니다. 앱 자격정보가 없으면 로그인 연결이 준비되지 않은 상태로 표시합니다.

- 로그인 설정·콜백·환경변수·세션 경계: [AUTH_SETUP.md](AUTH_SETUP.md)
- 추천 계산·임시 프로필·제작진 매칭·테마 규칙: [RECOMMENDATION_RULES.md](RECOMMENDATION_RULES.md)

## 카탈로그와 추천 근거

Supabase `contents`와 작품의 태그·감상처·제작진·복잡도 정보를 읽으며 원본 ID를 유지합니다. 500행씩 모든 페이지를 확인한 후 화면을 표시합니다. 중간 조회가 실패하거나 수량·ID가 일치하지 않으면 이전 자료를 표시하지 않고 재시도를 안내합니다. `HOLD`는 기존 공개 조회 정책에 따라 제외합니다.

소개·연도·이미지·감상처는 DB 값을 사용합니다. 확인된 성인 작품의 원본 표지는 API에서 안내 이미지로 치환하며 현재 탐색에서는 제외합니다. 일반 표지는 공식 공급처 변경이나 로딩 실패가 발생할 수 있으며, 실패 시 작품명으로 대체합니다.

작가·제작진·배우의 크레딧은 DB의 관계 행을 함께 읽습니다. 공식 인물 ID가 같은 경우만 동일 인물 또는 명시된 창작 스튜디오로 연결합니다. 공식 ID가 없는 같은 이름의 감독·작가는 **동명 포함 후보**이며 동일 인물 확인으로 취급하지 않습니다. 여러 작가를 묶은 공동 계정은 같은 작가 추천에서 제외합니다. 화면 매체의 ‘같은 감독’에는 감독 역할만 사용합니다.

현재 메인 추천은 태그 기반입니다. DB의 4축·서사 엔진·복잡도 지표도 전달하지만, 이를 현재 화면의 확정 추천 점수나 공식 플랫폼 평가로 설명하지 않습니다. 복잡도 등 미확인 값은 `null`로 유지합니다. 현재 메인과 기존 `/taste/`의 v16 1,700편 데이터·계산 로직은 별개이며 자동으로 같은 모델에 동기화되지 않습니다.

카탈로그는 페이지를 열거나 새로고침할 때 DB에서 조회합니다. 일반 태그는 `contents.tag_slugs_cache`와 `tag_dictionary`를 연결하므로 존재하지 않는 `content_tags` 테이블에 의존하지 않습니다. 이 연결 작업은 DB 데이터를 수정하거나 권한을 확장하지 않습니다.

## 인기순위 출처와 갱신

인기순위 파일의 마지막 생성 시각은 **2026-10-22 19:01:59 KST**입니다. 각 목록의 `observedAt`은 실제 조회 시각이고 `period`는 제공자가 집계한 기간입니다. 생성 시각과 집계기간을 같은 값으로 취급하지 않습니다.

| --- | --- | --- |
| 웹툰·만화 | [네이버 시리즈 만화 TOP 100](https://series.naver.com/comic/top100List.series?categoryCode=ALL&rankingTypeCode=DAILY) 100편 | 공식 일간 순위. 페이지에 정확한 집계 시작·종료 시각은 미표기 |
| 웹소설 | [네이버 시리즈 웹소설 TOP 100](https://series.naver.com/novel/top100List.series?categoryCode=ALL&rankingTypeCode=DAILY) 100편 | 공식 일간 순위. 정확한 시작·종료 시각은 미표기 |
| 영화 | [Netflix 한국 영화 TOP 10](https://www.netflix.com/tudum/top10/south-korea) 10편 | 2026-10-12~2026-10-18 주간 |
| 드라마·OTT | [Netflix 한국 TV TOP 10](https://www.netflix.com/tudum/top10/south-korea/tv) 10편 | 같은 주간. 드라마 외 예능·애니메이션도 포함 |


순위의 일부 작품만 기존 카탈로그와 연결되어 있습니다. 연결하지 못한 작품도 공식 제목·원순위·공식 링크를 보존합니다. 단행본이나 특정 시즌과 전체 작품이 다른 경우 매칭 근거와 판본 차이를 기록합니다. 작품을 필터링한 뒤 원래 8위가 1위로 바뀌도록 순위를 다시 매기지 않습니다.

애니메이션 전용 인기 탭은 화면에서 제거했습니다. 보존된 원본 순위 파일은 변경하지 않았습니다.

KOBIS·카카오·라프텔은 이번 조회에서 충분한 공식 순위 자료를 확보하지 못해 `unavailable`과 사유를 기록했습니다. 카탈로그 ID 순서나 편집자의 선택을 실시간 인기로 대신 표시하지 않습니다.

Python 3가 있는 환경에서 프로젝트 폴더를 기준으로 다음을 실행합니다.

```sh
# 공식 페이지를 다시 조회하고 popular.json과 근거 보고서를 갱신
python scripts/update-popular.py

# 이미 저장한 근거로만 다시 생성. 최신 순위를 조회하는 명령은 아님
python scripts/update-popular.py --cached
```

**예약 갱신은 설정되어 있지 않습니다.** 새 자료를 운영 화면에 반영하려면 갱신 결과를 검토한 뒤 다시 빌드·배포해야 합니다. 공식 페이지 구조가 바뀌면 수집기를 수정해야 할 수 있습니다.

## 자동 테마 추천

- 작품별 태그는 DB의 `anniversary_tags`, `season_tags`, `weather_tags`에서 읽습니다. 한 작품에 여러 태그를 사용할 수 있으며 일반 장르로부터 임의 추정하지 않습니다. 추천 근거 원장은 별도 콘텐츠 자료에 보존합니다.
- 계절과 기념일 날짜는 Asia/Seoul 기준입니다. 한국 기념일의 앞뒤 7일을 모두 포함하며, 겹치는 기념일은 기념일 추천 차례마다 돌아가며 표시합니다. 설날·추석 날짜는 공식 월력요항으로 확인한 2025–2027년 표를 사용합니다. 이후 연도의 공식 발표를 확인해 표를 갱신해야 합니다.
- 방문자가 페이지를 새로 열거나 새로고침할 때 한 번 선정하고, 페이지 안에서 필터·취향을 변경해도 테마를 다시 추첨하지 않습니다. 같은 브라우저의 누적 방문에서 날씨 6 : 기념일 3 : 계절 1을 적용합니다. 날씨+계절은 6:1, 기념일+계절은 3:1이며 계절만 있으면 항상 계절을 표시합니다. 실제 추천 작품이 없는 종류는 제외합니다.
- 추천 순환 상태는 브라우저에 저장합니다. 저장을 차단하거나 다른 브라우저를 쓰면 이전 방문과의 교대 기록을 이어갈 수 없습니다.
- 날씨는 Vercel 접속 지역을 자동 감지하여 MET Norway의 현재 시간대 1시간 예보를 조회합니다. GPS 권한이나 날씨 API 키는 필요 없습니다. 비·폭풍과 눈만 적용하고, 조회 실패나 지역 미확인 시 나머지 추천으로 이어집니다. localhost에서는 지역을 확인할 수 없으므로 계절·기념일을 보여줍니다. 자세한 운영 사항은 [WEATHER_SETUP.md](WEATHER_SETUP.md)를 참고합니다.
- 주제 배경과 미리보기 작품도 선정한 테마에 맞춥니다. 테마 태그를 표시·관리하는 화면은 제공하지 않습니다. DB 컬럼을 수정하면 다음 조회에 반영됩니다.

- `public/facets.js`: 태그 AND 검색과 현재 결과의 집계
- `public/context.js`, `public/context.css`, `public/data/context-tags.json`: 자동 테마 선정·배경·근거 태그
- `api/weather.js`, `server/weather.mjs`: 접속 지역 예보 조회
- `public/auth.js`, `api/auth.js`, `server/auth.mjs`: 로그인 화면과 서버 인증
- `api/catalog.js`, `server/catalog.mjs`, `server/catalog-model.mjs`, `public/catalog-client.js`: 최신 DB 조회·공개 필드 변환·전체 페이지 검증
- `public/data/popular.json`: 별도 공식 인기순위 자료. 과거 카탈로그 JSON은 회귀 테스트 참고용이며 빌드 결과에 포함하지 않습니다.
- `public/assets/ad-wide.svg`, `public/assets/ad-square.svg`: 임시 광고 이미지
- `public/taste/`: 기존 v16 취향테스트 통합본
- `scripts/build-catalog.py`: 제공 CSV에서 공개 카탈로그 재생성. 원본 폴더 구조가 필요함
- `scripts/update-popular.py`, `reports/popular-*.json`: 순위 갱신과 조회 근거
- `reports/catalog-*.json`: 데이터·인물 연결·결측값 검증 기록
- `verification/`: 브라우저 검증 기록과 캡처

광고를 바꾸려면 이미지 파일과 해당 HTML 대체 텍스트를 함께 변경합니다. 원본 자료와 비밀 환경변수 파일은 `public/` 또는 `dist/`에 넣지 않습니다.

## 빌드와 Vercel 배포

```sh
npm run check
node --test scripts/test-recommendation.mjs
node --test scripts/test-auth.mjs
npm run build
```

Vercel 설정은 Framework Preset `Other`, Build Command `npm run build`, Output Directory `dist`입니다. 프로젝트 루트는 이 README가 있는 폴더입니다. **DB·OAuth·날씨 함수를 포함하려면 `dist/`만 올리지 말고 프로젝트 루트 전체를 배포**해야 합니다. DB 조회에는 두 Supabase 환경변수가 필요하고, 실제 로그인에는 [AUTH_SETUP.md](AUTH_SETUP.md)의 서버 환경변수가 별도로 필요합니다. `.env.local`은 업로드하지 않습니다.

기존 Vercel 연결 확인에서 팀 상세 조회가 403을 반환해 이 작업에서는 원격 배포를 완료하지 않았습니다. 로컬 빌드 완료를 `chalpick.kr` 운영 반영 완료로 해석하지 않습니다. 배포 권한과 인증 설정을 갖춘 환경에서 미리보기 배포와 실제 로그인 동작을 확인한 뒤 운영에 반영합니다.

## 검증 범위

최신 DB 연결: 자동 시험 112개, 정적 검사, 빌드 통과. 실제 Supabase를 HTTP API로 21페이지 조회하여 10,170편·판타지 전체 1,291편을 검증했습니다. 확인된 성인 208편을 제외하면 탐색 9,962편·판타지 1,284편입니다. localhost에서 필터 및 신규 영화 《화양연화》 검색·상세·감상 링크를 확인했습니다. `verification/live-catalog.json`에 실제 조회 기록이 있습니다. 운영 Vercel 배포는 아직 하지 않았습니다.

이전 정적 v4 검증 기록: 정적 검사·빌드·80개 테스트(인증 26, 추천 17, AND 필터 2, 테마 순환 20, 날씨 15) 통과. 당시 브라우저에서 영화 307편, 판타지+액션 108편 → 회귀 16편 → 먼치킨 2편의 원본 일치를 확인했습니다. 이 수치는 최신 DB의 작품 수가 아닙니다. 이전 테마 시나리오는 `verification/context-scenarios-v4.json`에 보존합니다.

테마 자료는 44작품에 태그별 근거를 연결했습니다. 개천절은 현재 카탈로그와 확인 가능한 추천 근거가 겹치는 후보가 없어 비워뒀습니다. 계절별·날씨별 커버리지는 `reports/context-coverage.json`에 있으며, 추후 DB의 별도 컬럼으로 관리할 데이터입니다. 날씨는 실제 MET 응답까지 확인했으나 Vercel 자동 접속 지역은 운영 배포 후 확인이 필요합니다.

2026-10-22 v3 확인: 정적 검사·빌드 성공. 브라우저에서 상단 메뉴·취향테스트 링크 제거, 네 가지 매체 선택, 문피아·미스터블루 필터 제거를 확인했습니다. 액션 402편 → 무림·문파 추가 33편 → 먼치킨 추가 8편의 결과와 세 분류의 태그 수를 원본 카탈로그와 대조했습니다. 개수 내림차순과 0개 음영, 매체 변경 시 조건 유지, 0개 결과의 선택 해제, 전체 초기화를 확인했습니다. 광고는 임시 이미지를 유지하며 실제 광고망이나 추적 코드는 추가하지 않았습니다.

2026-10-22 v2 최종 확인: 정적 검사, 인증 26개와 추천 18개 테스트(총 44개), 빌드가 모두 통과했습니다. 실제 브라우저에서 취향 변경과 임시 프로필 복원, 복합 필터 11편의 원본 일치, 작가·감독 연결과 배우 검색, 광복절·비 오는 날 추천, 공식 인기순위 표기, 보관함, 320·390·1440px 레이아웃과 모바일 추천 넘김을 확인했습니다. 브라우저 오류 로그는 없었습니다. 캡처는 `verification/*-v2.png`에 있습니다.

서비스 소유자가 직접 설정할 항목은 [로그인 연결 안내](로그인_연결_안내.txt)에 짧게 정리했습니다.

추천·필터·테마·날씨 검증은 실제 카탈로그와 작은 시험 집합을 함께 사용합니다. 성인 제외, 취향 정렬, AND 검색, 태그 수, 명시적 테마 일치, 6:3:1 순환, 기념일 교대, 서울 날짜 경계, 지역 미확인 폴백과 예보 캐시를 검사합니다.

인증 테스트는 모의 제공자 응답으로 서버 흐름과 세션 검증을 확인합니다. 실제 제공자 앱 자격정보가 없는 상태에서 네이버·카카오 실계정 로그인까지 검증했다고 주장하지 않습니다. `verification/`의 브라우저 결과는 기록된 화면 버전과 시각을 기준으로 확인합니다.
