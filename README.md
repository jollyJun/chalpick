## 배포

브라우저 업로드용 ZIP을 풀고 그 안의 api, public, scripts, server 폴더와 파일을 GitHub 저장소 최상위에 올립니다. ZIP 자체나 바깥 폴더를 올리지 않습니다. 파일은 모두 한 번의 업로드에 포함할 수 있도록 100개 미만으로 구성합니다.

기존 폴더를 통째로 지우지 말고 같은 경로의 파일을 교체하세요. 이 버전에는 DB 변경 SQL이 필요하지 않습니다. 과거 전체 교체 SQL을 다시 실행하지 않습니다. 실제 비밀번호·비밀키·.env.local·DB 백업은 업로드하지 않습니다.

Vercel: Framework Other, Root Directory 저장소 최상위, Build Command npm run build, Output Directory dist. 기존 환경변수는 유지합니다. 배포 완료 후 모바일에서 새로고침하고 첫 화면과 공식 앱 이동을 확인하세요.

환경변수 이름은 SUPABASE_URL 및 SUPABASE_PUBLISHABLE_KEY(또는 기존 SUPABASE_ANON_KEY)입니다. 값은 GitHub가 아니라 Vercel 설정에만 보관합니다. URL을 변수 이름 칸에 입력하지 않습니다.

## 실행·검증

Node.js 24를 사용하며 추가 npm 설치는 필요하지 않습니다.

- npm run build: 검증된 첫 화면과 공개 검색 자료를 dist에 생성합니다.
- npm run check: 모듈 구문, 파일 경로, 공개 파일의 비밀키 포함 여부를 검사합니다.
- node scripts/preview.mjs: v8 로컬 미리보기 http://localhost:4175/ 를 엽니다.
- npm test: 전체 개발 소스에서 실행합니다. 경량 웹 업로드본에는 테스트 원본을 포함하지 않습니다.

운영 빌드는 설정된 DB 전체를 읽어 검증한 후 배포본을 만듭니다. DB 자료는 다음 성공한 빌드부터 반영됩니다. 로컬에 DB 설정이 없으면 동봉된 검증 완료 배포본을 사용합니다. 이번 UI 수정은 DB를 변경하지 않습니다.

## 개인정보·로직 공개 범위

화면에서 산식과 내부 설명을 없앤 것은 UI 정리이며 코드 보호 기능이 아닙니다. 브라우저가 실행하는 추천 코드와 내려받는 공개 작품 자료는 개발자 도구에서 확인할 수 있습니다. 추천 산식 자체를 비공개로 하려면 추천 계산과 필요한 데이터 처리를 서버로 이전해야 합니다.

GitHub 저장소가 공개라면 업로드한 소스와 문서도 공개됩니다. 과거 버전에 있던 RECOMMENDATION_RULES.md를 새 업로드본에는 넣지 않았지만 업로드만으로 기존 원격 파일이나 Git 기록이 삭제되지는 않습니다. 비공개 운영이 필요하면 저장소 공개 범위도 별도로 검토하세요.

## 앱 연결 한계

설치 앱 실행은 기기·브라우저·앱 버전에 영향을 받습니다. 검증되지 않은 스킴을 추측해 넣지 않았습니다. 네이버웹툰 Android는 정확한 작품 ID와 웹 대체 경로를 사용합니다. iOS는 공식 Universal Link를 사용하며 앱 미설치 시 네이버 설치 안내가 나타날 수 있습니다. 모든 플랫폼의 앱 실행을 보장하지 않습니다. 실제 휴대폰에서 설치·미설치 상태 확인이 필요합니다.
